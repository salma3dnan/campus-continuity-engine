# CV / Portfolio Project Description

**Campus Continuity Engine — Explainable Scheduling Recovery Decision-Support System**

Designed and implemented a full-stack university disruption recovery application using React, TypeScript, FastAPI, SQLAlchemy, Alembic and PostgreSQL. Built deterministic constraint-based recovery planning that detects classes affected by room closures, network outages and equipment failures, evaluates room capacity and resource requirements, ranks complete non-conflicting reassignment plans, and explains rejected candidates. Secured administrator approvals through transactional PostgreSQL row locking, a database-level exclusion constraint that prevents double-booking, stale-plan validation and audit records. Developed automated Python/PostgreSQL integration and concurrency tests, React component tests and browser-level workflow checks using synthetic university data.

**Keywords:** React · TypeScript · Python · FastAPI · PostgreSQL · SQLAlchemy · Database integrity · Constraint solving · REST API · Concurrency · Testing
